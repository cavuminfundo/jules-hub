**Goal:** Build and deploy Jules Hub (`cavuminfundo/jules-hub`), a self-hosted autonomous Junior Coder in Docker that works in isolated git worktrees, tests code changes, and escalates to Antigravity (Senior Coder) via CDP port 9000 for formal review and GitHub PR creation.

**Architecture:** Python FastAPI backend with modular subsystems (`hub/worktree_manager.py`, `hub/engine_router.py`, `hub/cdp_bridge.py`, `hub/app.py`) orchestrating isolated worktrees and 3 engine modes (`antigravity_flash`, `local` Ollama, `hybrid`). React/Tailwind dark-mode dashboard for cockpit monitoring, packaged as a multi-stage Docker image published to `ghcr.io/cavuminfundo/jules-hub:latest` and managed via Dockge.

**Tech Stack:** Python 3.12, FastAPI, Uvicorn, Pydantic, WebSockets (CDP client), Git, Docker/Dockge, Vite, React, Tailwind CSS, Pytest.

**Spec:** `/home/federico/jules/docs/superpowers/specs/2026-10-31-jules-hub-architecture-design.md`

## Global Constraints
- Target repository: `/home/federico/jules` (GitHub: `cavuminfundo/jules-hub`).
- Quota Shield: Default runtime must be `antigravity_flash` or `local` (Ollama RTX 5070 Ti :11434). Zero cloud Pro usage for junior scanning.
- Scope ceiling: Maximum 50 lines per atomic fix patch.
- Test gate: Project tests must pass baseline before edits; max 2 retries on failure; flag for escalation if tests do not pass.
- Container Hardening: Non-root execution (`user: "1000:1000"`), volume mount exclusively `/home/federico:/home/federico:rw` (strict ban on `/var/run/docker.sock` to prevent container breakout/privilege escalation), port `4100`.
- Command Injection Guard: All subprocess invocations (`git`, `gh`, `pytest`, `agy`, etc.) MUST use typed argument lists (`list[str]`) with `shell=False`. Strict prohibition of `shell=True` and raw string concatenation.
- Process Group Kill & Rollback: Test commands must kill the entire process group upon reaching the 120s timeout. `WorktreeContext.__exit__` must execute `git worktree remove --force` and `git worktree prune` on failure to guarantee zero dangling git locks.
- CDP port: `127.0.0.1:9000` for Antigravity desktop injection.
